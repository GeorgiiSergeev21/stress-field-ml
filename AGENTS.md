# Работа с репозиторием

- Используйте Python 3.12. Проверяйте изменения из корня командой `python -m pytest -q`.
- Помещайте переиспользуемый код в `src/`, сценарии экспериментов в
  `experiments/`, ноутбуки в `notebooks/`, описание методики в `docs/`.
- Храните локальные наборы данных в `data/`, а артефакты запусков в `results/`.
- Поддерживайте тесты запускаемыми без решателя ANSYS, GPU и графического сеанса.
- На этапе подготовки каркаса оставляйте математические алгоритмы и запуск
  ANSYS за рамками изменений.
