# Моделирование полей напряжений с помощью методов машинного обучения

Курсовая работа посвящена исследованию того, как методы машинного обучения
могут предсказывать поля напряжений. На текущем этапе подготовлен каркас
проекта. Модели, расчётные данные и интеграция с ANSYS появятся на следующих этапах.

## Установка и проверка

Команды для Bash из корня репозитория. Используйте Python 3.12.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m pytest -q
```

Минимальный тест проверяет чтение `config.yaml` через PyYAML и наличие
целочисленного значения для фиксации случайности. Для запуска теста достаточно
`python -m pip install pytest PyYAML`. Лицензия ANSYS, GPU и графический сеанс
для теста не требуются.

## Структура репозитория

| Путь | Назначение |
| --- | --- |
| `README.md` | Тема курсовой, настройка окружения и карта репозитория. |
| `AGENTS.md` | Правила внесения изменений и проверки проекта. |
| `requirements.txt` | Прямые зависимости Python для исследования, визуализации и тестов. |
| `.gitignore` | Исключения для окружений, кэшей, локальных данных и результатов расчётов. |
| `config.yaml` | Начальные настройки воспроизводимости и размещения артефактов. Пути заданы относительно корня репозитория. |
| `src/` | Будущий переиспользуемый код исследования. |
| `data/` | Локальные исходные и обработанные данные. |
| `tests/` | Автоматические проверки. |
| `tests/test_environment.py` | Минимальная проверка чтения конфигурации в Python-окружении. |
| `notebooks/` | Исследовательские ноутбуки. |
| `experiments/` | Будущие сценарии запуска и настройки отдельных экспериментов. |
| `results/` | Локальные метрики, графики и другие артефакты запусков. |
| `docs/` | Методика и материалы курсовой работы. |

Файлы `.gitkeep` позволяют отслеживать в Git пока пустые каталоги.
